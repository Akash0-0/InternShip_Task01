Ranking Signal Analysis — FlyRank ML Capstone

Abstract: This project studies which search/content signals correlate with visibility and engagement. A reproducible pipeline builds features from the FlyRank internship warehouse sample, compares a simple impressions baseline to a RandomForest model, and produces ranked recommendations for content actions.

Data

Sample: fact_content_daily_performance_sample.parquet from FlyRank/internship-warehouse (Hugging Face gated release). Key columns: impressions, clicks, avg position, GA4 engagement, scroll events, AI referral flags.

Methodology

  • Features: log(impressions), inverse position, GA4 engagement metrics, scroll events, AI-signal sum.
  • Label: clicked (gsc_clicks > 0).
  • Baseline: rank by impressions (log_impr).
  • Model: RandomForestClassifier trained on a sample; validation: random holdout for quick turnaround.

Results (sample run)

Model AUC: 0.8927. Baseline (log_impr) AUC: 0.8608.

Recommendations

  1. Monitor low-impression but high-position pages for indexing opportunities.
  2. Improve metadata / CTAs for visible pages with low CTR.
  3. Rewrite low-engagement pages showing traffic but little scroll or GA4 engagement.
  4. Protect top pages from risky edits and monitor for drops.
